# Meltype v1.4.1-mod1

公式 v1.4.1-pre.1 をベースに、文章入力時の `/` 中黒判定や記号追跡、ルートパス保護を改善した mod 版です。

## 本 mod での追加修正

- **文章入力欄での `/` の中黒入力改善**:
  - TSF の空欄や特定アプリで打ち始めた際、入力途中で英語記号判定が働いて `/` に戻ってしまう問題を直しました。
  - 設定「`/` キーで中黒『・』」が有効な場合、コード入力欄でも中黒として入力できるようにしました。
- **数字・記号入力後の状態リセット**:
  - 半角数字や英記号を直接打ったあと、Backspace で消して空欄に戻った際に内部の追跡状態をリセットし、再び日本語・中黒入力に戻るようにしました。
  - キャレット移動（クリックや矢印キー）時にも追跡状態を解除するようにしました。
- **ルートディレクトリの保護**:
  - `/bin`, `/usr`, `/etc`, `C:\` などの POSIX / macOS / Windows ルートパスが誤って日本語変換されるのを防ぎました。

## ベース版 (v1.4.1-pre.1) の変更点

- **日本語と英語の境界を、複数の区切り方の点数を比べて選ぶようにしました** (#1185)。
- カタカナ語の読みを増やし、ホスティングのような語も日本語として扱いやすくしました。
- 入力途中の英単語や、英単語に続く「する」の表示と区切りを調整しました。
- 英語の文節でも、変換エンジンの漢字候補を選べるようにしました (`go` の「後・語・碁」など)。
- Windows: 打鍵数のカウンターと分析を足しました。
- Windows: ユーザー辞書の窓と最小サイズを、画面の拡大率に合わせるようにしました。
